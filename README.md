# Tastemap

J’aimerais créer une application avec une carte globale des restaurants en France, leurs notes, leurs styles de nourriture (italien,chinois etc), des photos des plats, on doit être capable de filtrer en fonction de ces critères et ensuite de les voir apparaître sur la carte

This project was built with [Lovable](https://lovable.dev).
